# Vendored LaTeX support files

The files in this directory are copied from Sphinx's `sphinx/texinputs/`
directory (Sphinx 9.3.0+, https://www.sphinx-doc.org/):

* `sphinx.sty`, `sphinxhowto.cls`, `sphinxmanual.cls`
* `sphinxlatex*.sty`, `sphinxoptions*.sty`, `sphinxpackage*.sty`,
  `sphinxmessages.sty` (generated by Sphinx from its own sources)
* `python.ist`

They are distributed under the BSD 3-Clause license that covers Sphinx
(`Copyright (c) 2007-2026 by the Sphinx team`, see
`sphinx/LICENSE` in the reference checkout). They are vendored here so the
advanced `latex_elements["use_sphinx_sty"]` mode can copy them next to a
generated document. The default scribe LaTeX preamble is self-contained and
does not load these files.
