# scribe conformance report

> Generated by `cargo test -p scribe-cli --test conformance`.
> This is a **tracked metric**, not a pass/fail gate. The per-fixture
> baseline in `crates/scribe-cli/tests/fixtures/conformance_baseline.txt`
> is the regression guard.

Oracle: `sphinx-build 9.3.0+/035a07c32`

## Selection criteria

1. Deterministic, offline builds with no third-party services.  
2. Cover every parser/directive family: markup & inline, lists/tables,  
   footnotes/citations, admonitions, code/highlighting, include/raw/only,  
   toctree, glossary/productionlist, themes.  
3. Cover every implemented domain (py, c, cpp, js) plus xref warnings.  
4. `pseudoxml` compares doctree structure; `html` compares DOM markers.  
5. Keep the build count modest enough for regular CI runs.

## Rubric

- **Structure score** = multiset Jaccard overlap of element tag names
  (`pseudoxml` doctree tags or HTML tag names) between oracle and scribe.
- **Warning score** = Jaccard overlap of normalized warning lines
  (absolute paths and the `scribe: warning:` prefix removed; sorted).
- **Fixture score** = `0.85 * structure + 0.15 * warnings`.
- **Status**: `pass` >= 0.90, `partial` >= 0.50, else `fail`; fixtures
  needing unavailable features are `skip` with a recorded reason.
- **Aggregate parity** = mean fixture score over non-skipped fixtures.
